Getting started

From download to first rehearsal.

Set up while you have time to test. Alpha software should never be introduced for the first time immediately before an unrepeatable service.

  1. 01

    Download the installer

    Use the official button on this page. If needed, compare the file’s SHA-256 with the published value.

  2. 02

    Install for your Windows user

    Run the assisted installer and choose the installation location. Because this Alpha is unsigned, Windows may identify the publisher as unknown.

  3. 03

    Activate the device

    Launch while connected and enter the activation code supplied by your Project Worship administrator. Downloading does not provide an activation code.

  4. 04

    Create or open a workspace

    Choose the local church workspace that holds services, library content, media, settings, and display profiles.

  5. 05

    Prepare a first service

    Create or select a service, add songs, Scripture, media, or announcements from Resources, and check each item in Preview.

  6. 06

    Configure and test outputs

    Assign Audience and optional Stage displays, then rehearse representative cues and test Black, Logo, Freeze, and Clear before opening the service.

Already use Project Worship? Read the Alpha upgrade steps
  1. Create a current workspace backup and keep it outside the application install directory.
  2. Close Audience and Stage outputs, then stop presentation and media playback.
  3. Exit Project Worship normally. Install the new version or use Update Center.
  4. Reopen the existing workspace and verify services, media, themes, Screens assignments, settings, and Safety controls before opening outputs.

Do not uninstall the previous version or delete its data directory as an upgrade step. Preserve the original workspace and a verified backup.

Release notes

What changed in 0.1.0-alpha.5.

  • Stronger encrypted backup and restore verification, recovery, and retention-safe failure handling.
  • More reliable Preview-to-Live identity, output recovery, display state, and editor draft retention.
  • Live Tools keeps identity, current context, Close, and recovery actions reachable while content scrolls.
  • Compact Resources exposes every category through a labelled, keyboard-reachable overflow.
Read the authoritative GitHub release
Alpha limits

Use a backup and a tested fallback.

  • The installer is unsigned; verify its SHA-256.
  • Fresh-profile installation and several physical display checks remain incomplete.
  • Native screen-reader and Windows High Contrast checks remain incomplete.
  • Backup and restore responsiveness missed its predeclared target.

Project Worship Alpha should not be the only presentation system for an unrepeatable service.
